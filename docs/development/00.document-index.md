## 2. 사용·변경 규칙

- 문서 간 내용이 다르면 01 → 02 → 03 → 04 → 05 순으로 앞 문서가 우선한다. 단, 코칭 철학·금지 사항은 `CLAUDE.md`가 항상 우선한다.
- ID(BR·FR·RULE·NFR·FN·SCR·ENT·API·TC·DEC·RSK)는 승인 후 바꾸거나 재사용하지 않는다. 없애는 경우 "폐기"로 표시한다.
- 문서를 고치면 해당 문서의 버전·변경 내용 표를 갱신하고, 이 인덱스의 추적 요약을 확인한다.

## 4. 용어

| 용어 | 설명 |
|---|---|
| 삼코동 | 삼성그룹코칭 동호회 |
| 프로그램 | 기관 × 연도 × 차수 단위로 운영되는 코칭 과정. ID 예: `2026-2-DEMO-CAREER` |
| 회차·회기 | 프로그램 안의 개별 코칭 세션 |
| Between Session | 회기와 회기 사이에 고객이 관찰·실험을 하는 기간 |
| 고객 코드 | 실명 대신 쓰는 고객 식별 코드 (예: `C01`) |
| prefill | 구글폼 링크에 값을 붙여 문항을 미리 채우는 기능 |
| 코칭 툴 나눔터 | 코칭 도구 상세·워크시트를 모아 둔 외부 사이트 |
| Basic Auth | 브라우저 기본 비밀번호 창으로 사이트 접근을 제한하는 방식 |
| SSG | 빌드할 때 페이지를 미리 만들어 두는 방식 |
