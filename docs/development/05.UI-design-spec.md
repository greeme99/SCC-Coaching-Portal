## 3. 토큰

### 3.1 색상 (`DESIGN.md` §2 그대로)

| 용도 | 토큰 | 라이트 | 다크 |
|---|---|---|---|
| 앱 배경 | `--color-bg-base` | `#f8fafc` | `#0f172a` |
| 카드·사이드바 배경 | `--color-bg-surface` | `#ffffff` | `#1e293b` |
| 보조 배경·hover | `--color-bg-subtle` | `#f1f5f9` | `#334155` |
| 강조 | `--color-primary` | `#0066ff` | `#6366f1` |
| 선택 메뉴 배경 | `--color-primary-light` | `#e0edff` | `rgba(99,102,241,0.2)` |
| 구분선 | `--color-border-strong` | `#e2e8f0` | `#475569` |
| 제목 글자 | `--color-text-main` | `#0f172a` | `#f8fafc` |
| 본문 글자 | `--color-text-body` | `#334155` | `#cbd5e1` |
| 보조 글자·미제출 | `--color-text-muted` | `#94a3b8` | `#64748b` |

- 위 표의 hex 값은 설명용이다. 코드에서는 CSS 변수만 쓴다 (`DESIGN.md` §6).
- `--color-danger`, `--color-warning`은 이 앱에서 쓰지 않는다 (RULE-001).
- `--color-text-muted`(#94a3b8)는 흰 배경에서 대비가 4.5:1보다 낮다. **본문 크기 글자에는 쓰지 않고**, 기호(○·)와 13px 이상 굵은 보조 글자에만 쓴다. 읽어야 하는 보조 문장은 `--color-text-body`를 쓴다 (NFR-002).

### 3.2 타이포그래피

| 토큰 | 크기 | 굵기 | 줄 간격 | 사용처 |
|---|---|---|---|---|
| `--font-h1` | 30px | 700 | 1.2 | 화면 제목 |
| `--font-h2` | 22px | 600 | 1.3 | 카드·섹션 제목 |
| `--font-h3` | 18px | 600 | 1.4 | 패널 제목 |
| `--font-stat` | 28px | 700 | 1.2 | 프로그램 카드 숫자 (제출 합계) |
| `--font-body` | 15px | 400 | 1.5 | 본문·메뉴 |
| `--font-caption` | 13px | 500 | 1.4 | 묶음 제목, 배지, 범례 |

**폰트 (DEC-010):** `'Pretendard', 'Plus Jakarta Sans', 'Inter', -apple-system, BlinkMacSystemFont, sans-serif`
- 한글은 Pretendard(SIL OFL 1.1), 영문·숫자는 Pretendard 내장 글리프를 쓴다. 웹폰트 파일은 자체 호스팅한다(외부 CDN 의존 없음).
- `DESIGN.md` §3 폰트 목록 맨 앞에 Pretendard를 추가하는 수정을 함께 한다.

### 3.3 간격·곡률

간격 4·8·16·24·32·48px, 곡률 6px(배지)·10px(메뉴·버튼)·18px(카드)·9999px(알약형 버튼·상태 배지). 모두 `DESIGN.md` §3.

## 4. 사이드바 (제공 이미지 반영)

### 4.1 구조

| 요소 | 규격 |
|---|---|
| 상단 바 | 높이 64px, 배경 surface, 아래 1px 구분선(`--color-border-strong`). 왼쪽부터 ☰ 버튼 → 로고 → 서비스명 |
| ☰ 버튼 | 44×44px, 곡률 10px, 1px 테두리, 가운데 3줄 아이콘 |
| 로고 | 높이 40px (폭은 비율 2.84:1로 약 114px), 서비스명 "삼코동 코칭 포털" (`--font-h3`) |
| 사이드바 폭 | 280px (서랍 메뉴 300px, 화면 폭의 85% 이하), 배경 surface. 긴 회차 이름은 한 줄로 줄이고 말줄임(…), 전체 이름은 툴팁과 화면 낭독기로 제공 |
| 묶음 제목 | `--font-caption`, `--color-text-body`, 위 24px·아래 8px 여백, 아래 1px 구분선 |
| 메뉴 항목 | 높이 44px, 왼쪽 여백 16px, 아이콘 20px + 12px 간격 + 글자(`--font-body`) |
| 코칭 유형 행 | ● 점(8px, `--color-primary`) + 유형명(`--font-body` 600, `--color-primary`) + 오른쪽 ▾/▸ |
| 회차 항목 | 숫자 배지 24×24px(곡률 6px, `--color-bg-subtle` 배경, 1px 테두리, `--font-caption`) + "N회기 · 주제" |

### 4.2 선택 메뉴 (DEC-014, `DESIGN.md` §4-1 수정 사항)

| 상태 | 배경 | 글자·아이콘 | 기타 |
|---|---|---|---|
| 기본 | 없음 | `--color-text-body` | — |
| hover | `--color-bg-subtle` | `--color-text-main` | 전환 0.2s |
| 선택 | `--color-primary-light` | `--color-primary` (굵기 600) | 곡률 10px, 그림자 없음 |
| 키보드 초점 | 기존 배경 유지 | — | 2px `--color-primary` 바깥선, 2px 간격 |

`DESIGN.md` §4-1의 "진한 파란 배경 + 흰 글자 + 그림자"를 위 "선택" 행으로 바꾼다. 이유: 메뉴가 약 20개로 많아 진한 배경은 시선을 과하게 끈다.

### 4.3 아이콘

선 아이콘 1종 세트(굵기 1.75px, 20px)를 쓴다. 권장: Lucide(ISC 라이선스). 메뉴별 아이콘은 [02. PRD/FS](02.PRD-FS-functional-spec.md) FN-001 표를 따른다.

## 6. 상태 표현

| 상태 | 표현 |
|---|---|
| 로딩 | 스켈레톤 (`--color-bg-subtle` 블록, 은은한 밝기 변화). `prefers-reduced-motion`이면 변화 없음 |
| 빈 상태 | 회색 선 아이콘 + 한 문장 + 버튼 하나 |
| 오류 | 중립 카드 + "데이터를 불러오지 못했습니다" + 마지막 성공 시각 + [다시 시도]. 빨강 사용 안 함 |
| 차단(401·503) | 로고 + 안내 문장만 있는 단독 화면 |

## 7. 테마

- MVP는 라이트 테마만 표시한다. 다크 토큰은 `[data-theme="dark"]`로 함께 정의한다 (FR-013).
- 로고: 라이트 = `samkodong-logo-original.svg`, 다크 = `samkodong-logo-white-yellow.svg` (`CLAUDE.md` §8.5).

## 8. 접근성 (WCAG 2.1 AA)

| 항목 | 기준 |
|---|---|
| 대비 | 본문 글자 4.5:1 이상, 큰 글자·아이콘 3:1 이상 |
| 터치 영역 | 44×44px 이상 (태블릿 사용) |
| 초점 | 모든 상호작용 요소에 보이는 초점 표시 |
| 움직임 | `prefers-reduced-motion`이면 hover 이동·전환 효과 끔 |
| 의미 전달 | 제출 여부를 색만으로 전달하지 않음 (기호 + 화면 낭독 문구) |
| 확대 | 200% 확대에서 내용 손실 없음 |
