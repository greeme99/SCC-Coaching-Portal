## 2. 기술 스택

| 영역 | 선택 | 선택 기준 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 정적 페이지와 서버 API를 한 프로젝트에서 처리 (DEC-005) |
| 스타일 | Tailwind CSS (색은 CSS 변수 참조) | `DESIGN.md` 토큰 연결이 쉬움 |
| 호스팅 | Vercel Hobby (무료) | DEC-022 |
| 구글 연동 | `googleapis` 공식 클라이언트 (Sheets v4, Drive v3) | 서비스 계정 인증 지원 |
| 아이콘 | Lucide | 선 아이콘 1종 세트 (05 §4.3) |
| 폰트 | Pretendard (자체 호스팅) | DEC-010 |
| 테스트 | Vitest (단위), Playwright (화면·E2E) | Playwright는 이 개발 환경에 브라우저가 설치되어 있음 |

**버전 정책:** 착수 시점 안정판으로 고정하고 `package-lock.json`을 커밋한다 — Next.js 16.4.1, React 19.3, Tailwind CSS 4, TypeScript 5, Node.js 22, Vitest 5, Playwright 1.56(개발 환경에 설치된 Chromium과 맞춤). 주요 버전 올림은 별도 작업으로 한다.

**Next.js 16 주의:** middleware는 `proxy.ts`로 이름이 바뀌었다. `cacheComponents`(부분 프리렌더)를 켰기 때문에 `dynamicParams`·`revalidate` 같은 라우트 설정을 쓸 수 없고, 동적 주소의 잘못된 값은 `proxy.ts`에서 404로 돌린다(페이지 안 `notFound()`는 상태 코드가 200으로 나감).

## 3. 아키텍처 경계

```
브라우저 ──▶ proxy.ts (FN-002 비밀번호 확인, 잘못된 동적 주소 404)
              ├─▶ 정적 페이지 (SCR-004·005·010, SCR-006~009 본문)  ← content/ 파일로 빌드
              └─▶ 서버 (Route Handler·Server Component, 300초 캐시)
                     ├─ API-001 /api/programs ─────┐
                     ├─ API-002 /api/programs/{id}/progress ── Google Sheets API (읽기 전용)
                     └─ API-003 /api/references ─────── Google Drive API (메타데이터 읽기 전용)
외부 새 창: Google Forms (prefill 링크), 코칭 툴 나눔터, 드라이브 파일
```

| 경계 | 규칙 |
|---|---|
| `lib/google/*` | 구글 API 호출만 담당. 화면 코드는 이 모듈을 직접 부르지 않고 `lib/data/*`를 거친다 |
| `lib/data/*` | 시트 행 → 엔터티 변환, 완료 판정(RULE-004·009·011·012·013) |
| `lib/prefill.ts` | prefill 링크 생성 (브라우저·서버 공용 순수 함수) |
| `content/` | 콘텐츠 데이터. 코드 없음 |

## 5. 데이터·API 구현 방식

| 항목 | 방식 |
|---|---|
| 시트 읽기 | `spreadsheets.values.batchGet`으로 `programs`·`roster`·응답 시트 4종을 한 번에 읽기. 첫 행을 열 이름으로 사용 |
| 캐시 | Next.js `unstable_cache` 또는 `fetch` 캐시로 300초. 캐시 키 = 시트 ID |
| 드라이브 목록 | `files.list` (`'{폴더ID}' in parents and trashed=false`, 필드: id, name, mimeType, modifiedTime, webViewLink) |
| 정규화 | 키 값 앞뒤 공백 제거·대문자 통일 후 비교 (RULE-004) |
| 오류 | 구글 API 실패 → `UPSTREAM_ERROR`(502) + 마지막 성공 캐시가 있으면 함께 반환 |
| 백그라운드 작업 | 없음 (요청 시 조회 + 캐시) |

**환경변수 (`.env.example`에는 이름만)**

| 이름 | 용도 |
|---|---|
| `SITE_PASSWORD` | 공용 비밀번호 (FN-002) |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 서비스 계정 키 (JSON 문자열) |
| `SHEET_PROGRAMS_ID`, `SHEET_ROSTER_ID` | 운영 시트 ID |
| `SHEET_RESPONSES_ID` | 응답 시트 ID (탭 4개: 응답_코칭일지·응답_완료보고서·응답_코치종료소감·응답_피코치종료소감, DEC-024) |
| `DRIVE_REFERENCES_FOLDER_ID` | 참조자료 폴더 ID |
| `TOOL_HUB_URL` | 나눔터 주소 (기본값 있음) |

## 6. 보안·개인정보 통제

| 통제 | 구현 |
|---|---|
| 접근 제한 | `proxy.ts`에서 Basic Auth 확인, 상수 시간 비교. `SITE_PASSWORD` 없으면 503 |
| 최소 권한 | 서비스 계정 범위 `spreadsheets.readonly`, `drive.metadata.readonly`. 대상 시트·폴더에만 "보기 권한"으로 공유 |
| 응답 최소화 | API 응답에서 이름·이메일·응답 내용 제거 (RULE-003, RULE-008) |
| 보안 헤더 | CSP (`frame-src` = 나눔터 주소만, `frame-ancestors 'none'`, `object-src 'none'`, `base-uri 'self'`), `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`, `X-Robots-Tag: noindex`. `default-src 'self'`는 Next.js 인라인 스크립트와 충돌해 적용하지 않음 (필요 시 nonce 방식으로 강화) |
| 검색 노출 차단 | `robots.txt` 전체 차단 + `noindex` 메타 |
| 비밀값 | 환경변수만 사용, 저장소 커밋 금지, Vercel 대시보드에서만 설정 |

## 7. UI 구현 원칙

- 색은 CSS 변수만 사용. Tailwind `theme.extend.colors`가 변수를 참조 (예: `primary: 'var(--color-primary)'`).
- `scripts/design-lint.mjs`: `app/`, `components/`에서 hex 색상 직접 사용, 기본 순색 클래스(`text-red-500` 등), 정렬 가능한 표의 정렬 기호 누락을 찾아 실패 처리 (`DESIGN.md` §6). `DESIGN.md`의 `npm.cmd run design:lint`는 Windows 표기이며, 실제 스크립트 이름은 `npm run design:lint`.
- 화면 문구는 한국어, 코드 식별자는 영어, 주석은 한글 (`CLAUDE.md` §8.3).
- 사이드바·상태 표현은 [05. UI 설계서](05.UI-design-spec.md) §4·§6을 그대로 구현.

## 11. 공급망 관리

- 의존성은 꼭 필요한 것만 추가한다 (`CLAUDE.md` §8.3 단순성).

- 잠금 파일(`package-lock.json`)을 커밋하고 설치는 `npm ci`로 한다.
