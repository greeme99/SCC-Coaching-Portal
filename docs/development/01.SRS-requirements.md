## 1. 목적과 배경

**Summary:** 삼코동 코치가 프로그램별 다회기 코칭을 준비·진행·기록·모니터링하는 과정을 하나의 반응형 웹앱으로 묶는다.

| 항목 | 내용 |
|---|---|
| 조직 | 삼코동 (삼성그룹코칭 동호회) |
| 현재 문제 | 가이드북·기록 양식·진행 현황이 문서와 파일로 흩어져 있어, 회기 전 준비와 회기 후 기록이 누락되기 쉽고 회기 간 맥락을 한곳에서 보기 어렵다 |
| 목표 | ① 회기 준비에 필요한 가이드를 화면 하나에서 참조 ② 회기 후 기록을 구글폼으로 빠짐없이 작성 ③ 프로그램별 진행 현황을 한눈에 확인 |
| 사용자 | 코치 (단일 역할). 피코치(고객)는 앱을 쓰지 않고 구글폼 링크로만 응답 |
| 이해관계자 | 프로젝트 오너(승인), 코치 운영진(폼 문항·콘텐츠 검수), 관리자(구글 계정·시트 소유) |

## 6. 업무 규칙

| ID | 규칙 | 예외·처리 |
|---|---|---|
| RULE-001 | 미제출·예정 항목은 중립 색(`--color-text-muted`)과 중립 문구로만 표시한다. 빨강·주황 상태 색, "지연", "미이행" 같은 문구를 쓰지 않는다 | 없음 |
| RULE-002 | 고객·코치별 점수, 순위, 완료율 비교를 표시하지 않는다 | 프로그램 전체 제출 건수 합계는 표시 가능 |
| RULE-003 | 앱은 응답 내용을 표시하지 않고 제출 여부와 제출 일시만 표시한다 | 응답 내용은 관리자 구글 드라이브에서만 열람 |
| RULE-004 | 응답 매칭 키는 `programId + clientCode`이며, 코칭일지는 `sessionNo`를 더한다 | 키 값 앞뒤 공백·대소문자는 정규화 후 비교 |
| RULE-005 | `programId` 형식은 `{연도}-{차수}-{기관}-{유형}`이며, 차수는 1 또는 2다 (기관당 연 최대 2회) | 형식에 맞지 않는 행은 목록에서 빼고 "형식 오류 n건"을 안내 |
| RULE-006 | 시트와 드라이브는 읽기 전용 권한으로만 조회하며, 결과를 다른 저장소·파일에 복제하지 않는다 | 메모리 캐시(최대 5분)만 허용 |
| RULE-007 | 가이드 문구는 가이드북 원문을 그대로 쓰고 요약·재작성하지 않는다 | 원문의 외부 출처 링크는 옮기지 않는다 |
| RULE-008 | 이름·이메일은 `roster` 시트에만 둔다. 화면에는 고객 코드만 표시한다 | 없음 |
| RULE-009 | 종료소감(코치·피코치)은 종료 리포트 제출 이후에 작성한다 | 종료 리포트 없이 종료소감이 먼저 들어오면 제출로 표시하되 "작성 순서 확인" 안내를 중립 문구로 표시 |
| RULE-010 | 프로그램 상태(준비·운영중·종료)는 `programs` 시트 값을 따른다. 앱은 상태를 바꾸지 않는다 | 상태 값이 비어 있거나 다른 값이면 "상태 미지정"으로 표시 |
| RULE-011 | 같은 키의 응답이 여러 건이면 제출로 보고, 가장 최근 제출 일시를 표시한다 | 없음 |
| RULE-012 | 응답의 고객 코드가 `roster`에 없으면 표에 넣지 않고 "명단에 없는 응답 n건"을 안내한다 | 고객 코드 오타 확인용. 코드 값은 표시하지 않는다 |
| RULE-013 | 코칭일지 회차는 1부터 프로그램 회기 수까지이고, 추가 회차는 회기 수+1 ~ 99다 (DEC-025) | 추가 회차는 "추가 N회" 열로 표시. 숫자가 아니거나 1 ~ 99 밖인 회차는 RULE-012와 같은 방식으로 안내 |

| 접근 제한 | 공용 비밀번호 1개 — 입장 화면에서 입력, 세션 쿠키 30일 (DEC-029, 이전: HTTP Basic Auth). 비밀번호 변경은 Vercel 환경변수 수정 후 재배포하며, 바꾸면 기존 세션은 모두 끊긴다 |
| 권한 | 서비스 계정에 `spreadsheets.readonly`, `drive.metadata.readonly`만 부여. 대상 시트·폴더만 공유 |
| 참조자료 열람 | 파일 열기는 구글 드라이브 공유 설정을 따른다 (폴더 공유 범위는 관리자가 정함) |
| 외부 사이트 | 화면 삽입은 나눔터 주소 하나만 허용 (CSP⁵ `frame-src`) |
| 운영 | 비밀번호 유출 시 즉시 교체, 서비스 계정 키 연 1회 교체 권장 |

⁵ CSP: Content Security Policy. 브라우저가 불러올 수 있는 외부 자원을 제한하는 보안 설정
