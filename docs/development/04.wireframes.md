## SCR-001 앱 셸 (FN-001)

**목표:** 모든 화면에서 같은 위치의 메뉴로 이동한다.

```
데스크톱·태블릿 가로 (≥1024px)              태블릿 세로·모바일 (<1024px)
┌────────────────────────────────────┐    ┌───────────────────────┐
│ ☰ [로고] 삼코동 코칭 포털           │    │ ☰ [로고] 삼코동 코칭… │
├───────────┬────────────────────────┤    ├───────────────────────┤
│ 프로그램   │                        │    │                       │
│ ⌂ 프로그램 개요│                     │    │       본문            │
│───────────│                        │    │                       │
│ 코칭 모델  │                        │    └───────────────────────┘
│ ● 커리어 코칭 ▾      본문           │    ☰ 누르면 ↓ 왼쪽에서 서랍 메뉴
│                                    │    ┌──────────────┬────────┐
│                                    │    │ (사이드바 전체)│ 어두운  │
│                                    │    │              │ 배경   │
│  [0] 시작 세션                      │    └──────────────┴────────┘
│  [1] 1회기 · 나의 이야기와 현재 위치 │
│  … [5], [F] Follow-up              │
│ ● 멘토링 코칭 ▸                     │
│ ● 라이프 코칭 ▸                     │
│───────────│                        │
│ 일지·소감  │                        │
│ ✎ 코칭일지 … (4개)                  │
│───────────│                        │
│ 대시보드   │                        │
│ ▣ 프로그램 현황                     │
│───────────│                        │
│ 코치 도구  │                        │
│ ◍ 코칭 툴 나눔터                    │
│───────────│                        │
│ 자료       │                        │
│ ▤ 참조 자료실                       │
└───────────┴────────────────────────┘
```

| 구성요소 | 동작 |
|---|---|
| ☰ 버튼 | 사이드바 접기·펴기. `aria-expanded`, `aria-controls` 지정. 이름 "메뉴 열기/닫기" |
| 로고 | 대시보드로 이동. 대체 텍스트 `삼코동 Samsung Coaching Club` |
| 묶음 제목 | 작은 회색 글자 + 아래 구분선. 클릭 동작 없음 (`<h2>` 수준 제목 역할) |
| 코칭 유형 | ● + 유형명 + ▾/▸. 클릭 시 펼침·접힘 (`aria-expanded`) |
| 회차 항목 | 숫자 배지(0~5, F) + "N회기 · 주제". 현재 화면은 선택 스타일 + `aria-current="page"` |

| 항목 | 규칙 |
|---|---|
| 주요 행동 | 메뉴 선택 |
| 키보드 | Tab 순서: ☰ → 로고 → 메뉴 위에서 아래 → 본문. 서랍 메뉴가 열리면 초점이 메뉴 첫 항목으로, Esc로 닫고 초점은 ☰로 복귀. 서랍 열린 동안 초점이 메뉴 밖으로 나가지 않음 |
| 반응형 | ≥1024px: 사이드바 고정(폭 280px), 접으면 본문 전체 폭. <1024px: 서랍 메뉴(폭 300px, 화면 폭의 85% 이하) |
| 확대 | 200% 확대 시 <1024px 배치로 전환되어 가로 스크롤 없음 |
| 화면 낭독 | 사이드바는 `<nav aria-label="주 메뉴">`. 본문 시작 위치로 건너뛰는 "본문 바로가기" 링크 제공 |

## SCR-002 프로그램 현황 (FN-007)

**목표:** 프로그램을 골라 진행 현황으로 들어간다.

```
┌ 프로그램 현황 ───────────────────────────── 마지막 갱신 09:00 ┐
│ [상태: 운영중 ▾] [연도: 2026 ▾] [차수: 전체 ▾] [유형: 전체 ▾]  │
├──────────────────────────────────────────────────────────────┤
│ ┌───────────────────────┐ ┌───────────────────────┐          │
│ │ 예시 커리어 코칭 2026-2 │ │ 예시 멘토링 코칭 2026-2│          │
│ │ 커리어 · 운영중         │ │ 멘토링 · 운영중        │          │
│ │ 09.01 ~ 12.15 · 12명    │ │ 09.15 ~ 12.20 · 8명   │          │
│ │ 코칭일지 38 / 60        │ │ 코칭일지 12 / 40      │          │
│ │ 다음 일정 10.18      → │ │ 다음 일정 10.21    → │          │
│ └───────────────────────┘ └───────────────────────┘          │
└──────────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|---|---|
| 주요 행동 | 카드 선택 → SCR-003 |
| 상호작용 | 필터 변경 즉시 반영 + 주소 쿼리 갱신 |
| 로딩 | 카드 3개 스켈레톤 |
| 빈 상태 | "조건에 맞는 프로그램이 없습니다" + [필터 초기화] |
| 오류 | 공통 오류 + [다시 시도]. 형식 오류 행이 있으면 상단에 "형식이 맞지 않는 프로그램 n건은 표시하지 않았습니다" |
| 키보드 | 필터는 기본 `<select>`. 카드 전체가 하나의 링크 |
| 반응형 | ≥1024px 3열, 768~1023px 2열, <768px 1열. 필터는 <768px에서 2×2 |
| 화면 낭독 | 카드 링크 이름 = "프로그램명, 상태, 기간, 진행 현황 보기" |

## SCR-003 프로그램 진행 현황표 (FN-008)

**목표:** 고객별 기록 제출 여부를 확인한다.

```
┌ ← 프로그램 현황   예시 커리어 코칭 2026-2 · 운영중 · 09.01~12.15 ┐
│ 안내: 명단에 없는 응답 1건이 있습니다 (고객 코드 확인 필요)       │
├───────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┤
│고객 ⇅ │1회 ⇅ │2회 ⇅ │3회 ⇅ │4회 ⇅ │5회 ⇅ │리포트│코치소감│피코치│
├───────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ C01   │✓09.10│✓09.24│  ○   │  ·   │  ·   │  ·   │  ·   │  ·   │
│ C02   │✓09.11│  ○   │  ·   │  ·   │  ·   │  ·   │  ·   │  ·   │
└───────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
 ✓ 제출  ○ 예정일 지남  · 예정                    마지막 갱신 09:00
```

| 항목 | 내용 |
|---|---|
| 주요 행동 | 현황 확인 (편집 없음) |
| 상호작용 | 열 머리글 클릭으로 정렬 (고객 코드, 회차별 제출일). 비활성 열 `⇅`, 활성 열 `▲`/`▼` |
| 로딩 | 표 5행 스켈레톤 |
| 빈 상태 | "등록된 참여자가 없습니다. roster 시트에 고객을 추가하세요" |
| 오류 | 없는 programId → "프로그램을 찾을 수 없습니다" + [프로그램 현황으로] |
| 키보드 | 정렬 머리글은 버튼, `aria-sort` 지정 |
| 반응형 | 첫 열(고객 코드) 고정, 나머지는 표 영역 안에서 가로 스크롤 |
| 화면 낭독 | 기호 대신 칸 이름 읽기: "C01, 1회기 코칭일지, 제출, 9월 10일". 범례는 표 캡션에 포함 |

## SCR-004 프로그램 개요 (FN-003)

**목표:** 프로그램 내용과 진행 순서, 앱 사용 순서를 이해한다.

```
┌ 프로그램 개요 ─────────────────────────────────────────┐
│ 고객 주도형 다회기 코칭 프로그램 (설명 본문)             │
│ [운영 기본 사양 표]                                     │
│                                                       │
│ 그림 1. 코칭 여정                                       │
│ (시작)→(1회기)→[B1]→(2회기)→[B2]→(3회기)→[B3]→(4회기)   │
│        →[B4]→(5회기)→(Follow-up)                       │
│ 1. 시작 세션 — 이 과정에서 무엇을 얻고 싶은가? …         │
│                                                       │
│ 그림 2. 코치 업무 절차                                  │
│ ①세션 준비→②세션 진행→③코칭일지→④Between 안내          │
│ →⑤종료 리포트→⑥종료소감·링크 전달→⑦대시보드 확인         │
│ 1. 세션 준비 — 회차 가이드 확인 …                        │
└───────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|---|---|
| 주요 행동 | 그림의 단계 클릭 → 관련 화면 |
| 상태 | 정적 화면이라 로딩·오류 없음 |
| 키보드 | 그림의 각 단계는 링크(`<a>`), Tab으로 순서대로 이동 |
| 반응형 | ≥768px 가로 흐름(2줄 줄바꿈), <768px 세로 흐름 |
| 화면 낭독 | SVG는 `role="img"` + 제목. 상세 내용은 아래 순서 목록으로 전달 |

## SCR-005 회차 가이드 (FN-004)

**목표:** 세션 중 이 회차의 목적·질문·산출물·추천 도구를 바로 본다.

```
┌ 커리어 코칭 › 2회기 ──────────────────────────────────┐
│ [2] 가치·강점·환경 조건                                  │
│ 목적 ………………………………                                       │
│ ┌ 핵심 질문 ──────────────┐ ┌ 주요 산출물 ───────────┐ │
│ │ • “나는 어떤 일·환경에서 │ │ • 커리어 방향성 문장    │ │
│ │   나다워지는가?” …       │ └────────────────────────┘ │
│ └─────────────────────────┘                             │
│ ┌ 이 회기 추천 도구 ──────────────────────────────────┐ │
│ │ [우선] D-H-B — 행동·조건·존재방식의 균형 탐색   ↗   │ │
│ │ [보조] 자기결정성 점검                          ↗   │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌ 다음 Between Session: 강점·가치 사용 실험 ──────────┐ │
│ └────────────────────────────────────────────────────┘ │
│ ← 1회기                                      3회기 →   │
└───────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|---|---|
| 주요 행동 | 질문 참조, 추천 도구 열기(나눔터 새 창) |
| 상태 | 정적. 추천 도구 없으면 영역 숨김. 잘못된 주소는 SCR-013 |
| 키보드 | 제목 구조 h1(회차) → h2(목적·질문·산출물·도구·Between) |
| 반응형 | ≥1024px 질문·산출물 2열, 미만 1열. 태블릿에서 글자 크기 본문 15px 이상 유지 |
| 멘토링 유형 | 핵심 질문 아래 SHARE 5단계 카드 |

## SCR-006 ~ SCR-009 일지·소감 (FN-006)

**목표:** 정확한 값이 채워진 구글폼으로 기록한다.

```
┌ 코칭일지 ─────────────────────────────────────────────┐
│ 작성자: 코치 · 작성 시점: 매 회기 종료 후                 │
│ ┌ 질의 항목 미리보기 (최종 수정 2026-10-15) ──────────┐ │
│ │ 1. 고객이 선택한 의제 …                              │ │
│ │ 2. 핵심 자각 …                         [더 보기 ▾]  │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌ 폼 열기 ───────────────────────────────────────────┐ │
│ │ 프로그램 [2026-2-DEMO-CAREER ▾]                      │ │
│ │ 고객 코드 [C01 ▾]   회차 [3 ▾]    ← 코칭일지만 회차   │ │
│ │                          [ 구글폼 열기 ↗ ]          │ │
│ └────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────┘
회차 목록 끝 "추가 회차 (직접 입력)" → 아래에 [추가 회차 번호] 입력 칸 (회기 수+1 ~ 99)
SCR-009 피코치 종료소감: [구글폼 열기] 대신 [링크 복사] [공유]
```

| 항목 | 내용 |
|---|---|
| 주요 행동 | SCR-006~008: 구글폼 열기 / SCR-009: 링크 복사·공유 |
| 상호작용 | 프로그램 선택 → 고객 코드 목록 갱신. 필수 값을 모두 골라야 버튼 활성 |
| 로딩 | 선택 영역만 스켈레톤 (미리보기는 바로 표시) |
| 오류 | 목록 조회 실패 → "목록을 불러오지 못했습니다" + [값 없이 구글폼 열기] |
| 성공 | 복사 시 토스트 "링크를 복사했습니다". 클립보드 실패 시 링크 텍스트 상자를 선택된 상태로 표시 |
| 키보드 | 비활성 버튼은 `aria-disabled` + 이유 안내("프로그램과 고객 코드를 선택하세요") |
| 반응형 | <768px에서 선택 상자 세로 배치 |

## SCR-010 코칭 툴 나눔터 (FN-005)

```
┌ 코칭 툴 나눔터                     [새 창에서 열기 ↗] ┐
│ ┌──────────────────────────────────────────────────┐ │
│ │                                                  │ │
│ │        (나눔터 사이트 iframe, 남은 높이 전부)       │ │
│ │                                                  │ │
│ └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
불러오기 실패: "이 화면에서 나눔터를 표시할 수 없습니다. 새 창에서 열어 주세요." + [새 창에서 열기 ↗]
```

| 항목 | 내용 |
|---|---|
| 로딩 | iframe 위 "불러오는 중" 표시, 8초 초과 시 실패 안내로 전환 |
| 키보드 | iframe `title="코칭 툴 나눔터"`. 새 창 버튼이 iframe보다 먼저 초점 |
| 반응형 | iframe 높이 = 화면 높이 − 상단 바 − 제목 영역 |
