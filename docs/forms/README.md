## 앱 연계 전 확인할 사항

확정된 결정(CLAUDE.md §5.2·§7, DEC-006)과 맞지 않는 부분이다. 구글폼 문항을 고칠지 결정이 필요하다.

| 구분 | 양식 내용 | 확정 결정 |
|---|---|---|
| 개인정보 | ① 2번 "고객(멘티) 성함", ①③④ 이메일 수집 | 폼·응답에는 **고객 코드**만 쓴다. 이름·이메일은 `roster` 시트에만 둔다 |
| 완료 판정 키 | 프로그램 ID·고객 코드 문항 없음 | `프로그램 ID + 고객 코드 (+ 회차)`를 prefill¹로 채워 완료 여부를 판정한다 |
| 회차 선택지 | ① 3번 "1~5회차 + 기타" 고정 | 프로그램마다 회기 수가 다르다 (시작 세션·Follow-up 포함) |
| 척도 문항 | ③④ 3~11번 5점 척도 | 폼에서는 수집 가능. 앱 대시보드에는 **제출 여부만** 표시하고 점수·순위는 보여주지 않는다 (§6) |

¹ prefill: 구글폼 링크 뒤에 값을 붙여 특정 문항의 답을 미리 채워 두는 기능
