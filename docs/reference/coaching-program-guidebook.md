# 1. 프로그램 목적과 대상

## 1.1 프로그램 정의

본 프로그램은 고객이 삶, 학업, 진로, 관계, 일, 성장에 관한 중요한 선택을 외부의 기대, 비교, 불안에 끌려가기보다 **자신의 가치와 기준을 바탕으로 탐색하고 행동하도록 돕는 코칭 과정**입니다.

고객은 프로그램을 통해 다음 질문에 답할 수 있게 됩니다.

- 지금 나에게 실제로 중요한 문제 또는 선택은 무엇인가?
- 이 선택에서 내가 지키고 싶은 가치와 기준은 무엇인가?
- 나는 어떤 경험과 강점, 자원을 이미 가지고 있는가?
- 나를 멈추게 하는 사실, 해석, 예상은 각각 무엇인가?
- 지금 가능한 선택지는 무엇인가?
- 작은 행동을 통해 무엇을 확인하고 배울 수 있는가?
- 코칭 이후에도 스스로를 점검하고 조정하려면 어떤 질문을 해야 하는가?

## 1.2 프로그램 목표

| 자기이해 | 감정·생각·가치·욕구·강점 인식 | “나는 비교할 때 불안해지고, 배움과 협업을 중요하게 여긴다.” | 성찰지·세션 발화 |
| 의제 명료화 | 막연한 고민을 다룰 주제로 전환 | “진로가 막막하다” → “오래 몰입할 환경 조건을 알고 싶다.” | 세션 목표 |

| 지속성 | 종료 후 자기점검 루틴 유지 | “매주 일요일 10분 회고한다.” | 지속 계획·Follow-up |

# 2. 코칭의 정의와 철학

## 2.1 코칭 정의

> **코칭은 고객과 수평적 파트너십을 바탕으로 고객이 자신의 경험·생각·감정·가치·강점을 탐색하고, 중요한 선택의 기준을 발견하며, 스스로 행동하고 성찰하도록 돕는 과정이다.**

## 2.2 핵심 철학

1. 고객은 자신의 삶에 관한 가장 중요한 맥락을 알고 있다.
2. 고객에게는 이미 경험, 강점, 자원, 가능성이 있다.
3. 코치는 고객의 삶을 대신 판단하거나 결정하지 않는다.
4. 고객은 코칭의 의제, 목표, 행동의 주체다.
5. 코치는 해답 제시보다 질문, 경청, 반영, 요약, 성찰 지원을 우선한다.
6. 고객이 선택한 행동은 성과를 위한 숙제가 아니라 자신을 알아가는 실험이다.
7. 행동 결과는 성공·실패보다 배움과 조정의 정보다.
8. 코칭의 종료는 코치 의존의 끝이 아니라 고객의 자기성찰과 자기조절의 시작이다.

## 2.3 역할 구분

| 구분 | 고객의 역할 | 코치의 역할 |
|---|---|---|
| 의제 | 다루고 싶은 주제 선택 | 의제를 명료화하도록 지원 |
| 목표 | 원하는 변화와 의미 정의 | 목표의 중요성 탐색 |
| 해석 | 자기 경험에 의미 부여 | 다른 관점·패턴을 비판단적으로 비춤 |
| 행동 | 시도할 행동 선택 | 행동을 작고 구체적으로 설계하도록 지원 |
| 성찰 | 결과에서 배움 도출 | 평가 없이 학습을 촉진 |
| 지속 | 다음 선택과 점검 방식 결정 | 자기질문·자기관리 구조 형성 지원 |

# 3. 고객 주도성과 운영 원칙

## 3.1 운영 원칙 10가지

| 원칙 | 의미 | 코치 질문·행동 |
|---|---|---|
| 고객 의제 우선 | 고객이 중요하게 느끼는 주제를 다룸 | “오늘 가장 다루고 싶은 것은 무엇인가요?” |
| 지속적 합의 | 의제·목표·방식을 유연하게 조정 | “지금 더 중요한 것은 무엇인가요?” |
| 적극경청 | 말·감정·가치·침묵·반복 표현 경청 | “그 단어를 여러 번 쓰셨는데 어떤 의미인가요?” |
| 비판단적 호기심 | 원인·성격을 단정하지 않고 탐색 | “그 과정에서 어떤 일이 있었나요?” |
| 고객 언어 사용 | 전문용어보다 고객 표현 사용 | 고객의 ‘막막함’을 그대로 반영 |
| 자각 촉진 | 고객이 의미를 직접 발견하도록 지원 | “지금 새롭게 보이는 것은 무엇인가요?” |
| 선택지 확장 | 하나의 답에 갇히지 않게 함 | “다른 가능성이 있다면 무엇일까요?” |
| 작은 행동 | 행동을 부담 없는 실험으로 설계 | “10분만 한다면 무엇이 가능할까요?” |
| 학습 중심 | 미실행도 학습 정보로 다룸 | “그 경험이 알려준 것은 무엇인가요?” |
| 코치 성찰 | 조언 욕구·편견·감정 반응 관리 | 세션 후 자기성찰 기록 |

## 3.2 세션 합의의 기본 질문

| 확인 요소 | 질문 | 기록 예시 |
|---|---|---|

| 기대 결과 | “대화가 끝날 때 무엇이 분명해지면 좋을까요?” | “내가 막히는 지점 알기” |
| 중요성 | “그것이 지금 왜 중요한가요?” | “지원 시기가 다가오기 때문” |

## 3.3 고객 주도성을 약화시키는 행동

| 위험 행동 | 문제점 | 코칭적 전환 |
|---|---|---|
| 조언부터 함 | 고객 사고·선택 공간 축소 | 고객의 기준과 선택지를 먼저 탐색 |
| 질문 폭격 | 고객이 심문받는 느낌 | 질문 후 반영·침묵·요약 사용 |
| 코치가 목표 설정 | 고객 내적 동기 약화 | 고객이 원하는 변화 확인 |
| 도구 강요 | 고객 이야기가 모델에 맞춰짐 | 사용 전 동의와 목적 확인 |
| 긍정 강요 | 어려운 감정을 지움 | 감정을 인정하고 의미 탐색 |
| 미실행 비난 | 고객이 방어적으로 변함 | 실행 과정에서 일어난 일 탐색 |
| 과도한 칭찬 | 코치 평가가 중심이 됨 | 고객이 경험의 의미를 직접 해석하도록 지원 |

# 4. 일반 코칭 방법론과 세션 흐름

## 4.1 일반 코칭 순환

\[
\text{관계·안전} \rightarrow \text{의제 명료화} \rightarrow \text{탐색·경청} \rightarrow \text{자각·의미화} \rightarrow \text{선택지 확장} \rightarrow \text{행동 실험} \rightarrow \text{성찰·조정} \rightarrow \text{자기주도적 지속}
\]

이 흐름은 특정 모델의 절차가 아니라, 고객과의 대화가 균형 있게 진행되는지 점검하는 **일반 코칭 프레임**입니다.

## 4.2 단계별 운영 가이드

| 단계 | 목적 | 코치 역할 | 질문 예시 | 고객 산출물 |
|---|---|---|---|---|
| 관계·안전 | 편하게 말할 수 있는 공간 형성 | 존중·비판단·현재성 | “오늘 어떤 마음으로 오셨나요?” | 현재 상태 |
| 의제 명료화 | 오늘 다룰 한 가지 선택 | 초점·성공 기준 합의 | “오늘 무엇이 분명해지면 좋을까요?” | 세션 의제 |
| 탐색·경청 | 사실·생각·감정·가치·강점 탐색 | 경청·반영·침묵 | “그때 어떤 일이 있었나요?” | 핵심 맥락 |
| 자각·의미화 | 패턴·가치·욕구·강점 인식 | 통찰 확인·요약 | “새롭게 보이는 것은 무엇인가요?” | 핵심 통찰 |
| 선택지 확장 | 다양한 가능성 탐색 | 예외·가정·관점 질문 | “다른 선택도 있다면 무엇일까요?” | 선택지 |
| 행동 실험 | 작은 시도 선택 | 행동의 구체화·현실화 | “이번 주 작게 해볼 것은?” | 행동계획 |
| 성찰·조정 | 결과를 학습으로 전환 | 평가 대신 배움 탐색 | “해본 결과 무엇을 배웠나요?” | 회고·조정 |
| 지속 | 자기점검과 재선택 가능 | 자기질문 만들기 | “다음에 막히면 무엇을 묻겠나요?” | 자기질문 카드 |

## 4.3 재합의가 필요한 상황

| 상황 | 재합의 질문 |
|---|---|
| 새 주제 등장 | “새로 나온 주제가 오늘 더 중요하게 느껴지나요?” |
| 감정이 깊어짐 | “이 감정을 조금 더 탐색하는 것이 도움이 될까요?” |
| 시간이 부족함 | “남은 시간에는 무엇을 가장 다루고 싶나요?” |
| 고객이 답을 요구 | “지금 답이 필요하다는 마음에는 어떤 어려움이 있나요?” |
| 행동이 과도함 | “더 작고 가볍게 시작하면 무엇이 될까요?” |
| 도구가 맞지 않음 | “이 방식이 도움이 되는지, 다른 방식이 나을지 어떻게 느끼세요?” |

# 5. 전체 프로그램 운영 구조

## 5.1 프로그램 여정

| 단계 | 명칭 | 핵심 질문 | 주요 산출물 |
|---|---|---|---|
| 0회기 | 시작 세션 | “이 과정에서 무엇을 얻고 싶은가?” | 참여 합의서, 사전성찰지 |
| 1회기 | 나의 이야기와 현재 위치 | “나는 어떤 경험을 지나왔고 지금 어디에 있는가?” | My Story, 현재 위치 |
| Between 1 | 일상 관찰 | “내 감정과 에너지는 무엇을 알려주는가?” | 관찰일지 |
| 2회기 | 가치·강점·나답게 사는 방식 | “나는 무엇을 중요하게 여기고 어떤 힘을 가졌는가?” | 방향성 문장 |
| Between 2 | 강점·가치 사용 실험 | “내 강점을 실제로 어떻게 써볼 수 있는가?” | 실험 기록 |
| 3회기 | 미래 방향과 목표 이정표 | “앞으로 더 많이 경험하고 싶은 삶은 무엇인가?” | 미래 방향 지도 |
| Between 3 | 미래 검증 행동 | “그 방향을 확인하기 위해 무엇을 해볼 수 있는가?” | 행동실험 기록 |
| 4회기 | 선택지 확장과 실행 가능성 | “무엇이 나를 멈추게 하며 어떤 선택이 가능한가?” | 선택지·조정 계획 |
| Between 4 | 실행·관찰·조정 | “시도한 결과 무엇을 배우고 조정할 것인가?” | 실행 회고지 |
| 5회기 | 성장 통합과 지속 계획 | “앞으로 나는 어떻게 스스로를 점검할 것인가?” | 자기질문 카드·지속 계획 |
| Follow-up | 후속 점검 | “무엇을 유지·수정·새로 선택할 것인가?” | 후속 성찰 기록 |

## 5.2 Between Session 운영 원칙

- 고객이 기록·관찰·행동의 주제를 선택한다.
- 과제는 짧고 현실적이며 일상에서 가능한 수준으로 정한다.
- 기록은 완성도보다 관찰과 배움을 우선한다.
- 미실행은 다음 회기의 중요한 탐색 자료다.
- 코치는 고객을 감시하거나 평가하지 않는다.
- 기록 공유 범위와 연락 채널을 사전에 합의한다.
- 다음 회기에서는 기록의 양보다 고객이 발견한 의미를 다룬다.

## 6.4 회기 종료 점검

- [ ] 고객이 행동을 통해 무엇을 배울지 정했는가?
- [ ] 다음 회기에 연결할 성찰 질문이나 기록이 있는가?

# 7. 시작 세션: 연결·합의·방향 설정

## 7.1 목적

시작 세션은 인트로와 프리세션을 통합한 첫 만남입니다. 단순 안내가 아니라 고객이 안전하게 자기 이야기를 말하고, 의제를 선택하며, 이후 코칭 과정에 자발적으로 참여할 수 있게 하는 관계 형성 단계입니다.

## 7.2 합의 항목

| 항목 | 합의 내용 |
|---|---|
| 프로그램 목적 | 고객의 자기이해·선택·행동·성찰 지원 |
| 고객 역할 | 의제·목표·행동을 스스로 선택 |
| 코치 역할 | 질문·경청·반영·요약·성찰 지원 |
| 운영 구조 | 시작 세션, 1~5회기, Between Session, Follow-up |
| 기록 | 고객 성찰지 및 코치 운영기록 |
| 소통 | 연락 채널, 응답 범위, 연락 목적 |
| 비밀보장 | 사전 합의 범위에서 고객 정보 보호 |
| 목표 조정 | 고객은 언제든 의제·목표·방식 조정 요청 가능 |
| 종료 | 고객은 필요 시 중단·종료 요청 가능 |

## 7.3 핵심 질문

- “오늘 코칭을 시작하게 된 계기는 무엇인가요?”
- “요즘 가장 자주 떠오르는 생각은 무엇인가요?”
- “지금 삶·학업·진로·일에서 변화가 필요하다고 느끼는 부분은 어디인가요?”
- “이 과정에서 무엇이 달라지면 의미 있다고 느끼겠나요?”
- “이미 고객님에게 도움이 되는 강점·경험·사람·환경은 무엇인가요?”
- “생각을 정리할 때 어떤 방식이 가장 편한가요?”
- “대화에서 조심하거나 다루지 않았으면 하는 주제가 있나요?”

# 8. 1회기: 나의 이야기와 현재 위치

## 8.1 목적

1회기는 고객이 자신의 삶을 문제 목록이 아닌 경험·전환점·감정·강점·가치가 연결된 자기 이야기로 바라보도록 돕습니다.

## 8.2 핵심 질문

- “지금의 고객님을 만든 중요한 경험은 무엇인가요?”
- “그때 구체적으로 어떤 일이 있었나요?”
- “그 경험에서 가장 크게 느낀 감정은 무엇인가요?”
- “그 감정은 무엇이 중요하다고 알려주나요?”
- “그 시기를 지나오며 고객님이 해낸 것은 무엇인가요?”
- “그 경험은 현재의 선택과 어떻게 연결되나요?”
- “이번 주 무엇을 더 관찰해보고 싶나요?”

## 8.3 샘플 대화

> **고객**: “저는 어떤 일을 시작해도 오래 하지 못하는 것 같아요.”  
> **코치**: “오래 하지 못한다는 생각이 특히 강해지는 경험이 있나요?”  
> **고객**: “대학 때 동아리를 두 번 그만뒀어요.”  
> **코치**: “그 동아리에서 어떤 변화가 있었나요?”

# 17. 라이프 코칭 적용 가이드

## 17.1 라이프 코칭의 목적

라이프 코칭은 고객이 삶의 여러 영역에서 자신에게 중요한 가치, 삶의 리듬, 관계 방식, 에너지 사용 방식, 선택의 기준을 발견하고 보다 자신다운 삶을 만들어가도록 돕는 코칭입니다.

라이프 코칭의 목적은 더 바쁘고 효율적인 사람을 만드는 것이 아닙니다. 고객이 자신에게 맞는 삶의 방식과 우선순위를 발견하고, 현재의 삶에서 작지만 의미 있는 선택을 하도록 돕는 것입니다.

> “나는 어떤 삶을 살고 싶은가?”  
> “지금의 삶에서 무엇을 지키고, 무엇을 조정하고, 무엇을 새롭게 선택하고 싶은가?”  
> “나는 어떤 사람으로 존재하고 싶은가?”

## 17.2 주요 적용 의제

| 의제 영역 | 고객이 경험할 수 있는 고민 |
|---|---|
| 삶의 균형 | 일이 삶을 압도함, 휴식 부족, 역할 과다 |
| 에너지·회복 | 쉬어도 회복되지 않음, 무기력, 과부하 |
| 관계·경계 | 거절 어려움, 타인의 기대, 관계 피로 |
| 삶의 방향 | 성취는 있지만 만족이 낮음, 전환기 혼란 |
| 습관·자기관리 | 계획과 실행의 반복적 불일치 |
| 자기비판·완벽주의 | 잘하지 못할까 봐 시작을 미룸 |
| 의미·정체성 | “이대로 살아도 되는가?”라는 질문 |

## 17.3 라이프 코칭 운영 원칙

| 원칙 | 적용 의미 | 코치 질문 |
|---|---|---|
| 삶 전체를 본다 | 단일 문제보다 일·관계·건강·휴식·성장의 연결 탐색 | “이 문제가 다른 삶의 영역에는 어떤 영향을 주나요?” |
| 삶의 리듬 존중 | 사회적 기준보다 고객에게 맞는 속도 탐색 | “고객님에게 지속 가능한 리듬은 어떤 모습인가요?” |
| 에너지 흐름 탐색 | 시간관리보다 에너지 원천과 소진 요인 확인 | “언제 에너지가 오르고, 언제 소진되나요?” |
| 가치 기반 선택 | 해야 할 일보다 지키고 싶은 가치 확인 | “이 선택에서 놓치고 싶지 않은 것은 무엇인가요?” |
| 경계 탐색 | 거절·요청·거리의 기준을 고객이 설정 | “어떤 경계를 지킬 때 더 나다워질까요?” |
| 작은 회복 행동 | 거대한 변화보다 반복 가능한 회복 행동 | “이번 주 나를 돌보는 작은 행동 하나는?” |
| 자기비판 관찰 | 비판을 없애기보다 작동 방식 탐색 | “그 목소리는 무엇을 보호하려 하나요?” |

## 17.4 라이프 코칭 5회기 설계

| 회기 | 주제 | 고객 중심 질문 | 주요 산출물 |
|---|---|---|---|
| 1회기 | 삶의 이야기와 현재 위치 | “나는 지금 어떤 삶을 살고 있는가?” | 현재 삶의 지도 |
| 2회기 | 가치·강점·나다운 삶 | “나는 무엇을 지키며 어떤 사람으로 살고 싶은가?” | 라이프 방향성 문장 |
| 3회기 | 원하는 삶의 장면 | “앞으로 더 많이 경험하고 싶은 삶은 무엇인가?” | 미래 삶의 장면 |
| 4회기 | 선택지·경계·실행 | “무엇이 나를 멈추게 하며 무엇을 바꿀 수 있는가?” | 선택지·실행 계획 |
| 5회기 | 통합·회복·지속 | “나는 어떻게 나를 계속 돌보고 조정할 것인가?” | 회복·지속 계획 |

- “에너지를 주는 것과 빼앗는 것은 각각 무엇인가요?”
- “지금 삶에서 더 지키고 싶은 경계는 무엇인가요?”

- “다음 주를 조금 더 나답게 보내려면 무엇을 바꿀 수 있을까요?”
- “내가 나 자신에게 너무 엄격해지는 순간은 언제인가요?”
- “그때 나에게 필요한 더 친절하고 현실적인 질문은 무엇일까요?”

## 17.6 라이프 코칭 Between Session 예시

|---|---|---|

# 18. 커리어 코칭 적용 가이드

## 18.1 커리어 코칭의 목적

커리어 코칭은 고객이 직업명, 학벌, 스펙, 타인의 기대만을 기준으로 진로를 정하도록 돕는 것이 아닙니다. 고객이 자신의 흥미, 가치, 강점, 경험, 에너지, 환경 선호, 성장 방식을 근거로 자신에게 의미 있는 일과 성장 방향을 탐색·검증하도록 돕는 과정입니다.

> “나는 어떤 문제를 다루고 싶은가?”  
> “어떤 환경에서 강점과 에너지가 살아나는가?”  
> “어떤 경험을 통해 내 방향을 더 확인할 수 있는가?”  
> “남의 기준이 아니라 내 기준으로 다음 행동을 어떻게 선택할 것인가?”

## 18.2 커리어 탐색 6축

| 탐색 축 | 의미 | 질문 예시 |
|---|---|---|
| 흥미 | 무엇에 호기심·몰입이 생기는가 | “시간 가는 줄 모르고 했던 활동은?” |
| 가치 | 일에서 포기하기 어려운 기준 | “어떤 조건이 없으면 일해도 만족하기 어려울까요?” |
| 강점 | 어떤 방식으로 문제를 풀고 기여하는가 | “어려운 상황에서도 자연스럽게 해낸 것은?” |
| 경험 | 과거 경험의 행동·성과·배움 | “경험 속에서 반복되는 역할은?” |
| 환경 | 어떤 조직·관계·문화·업무 방식이 맞는가 | “어떤 환경에서 에너지가 살아나나요?” |
| 현실 | 시간·비용·지역·건강·책임 조건 | “반드시 고려해야 할 조건은?” |

## 18.3 커리어 코칭 5회기 설계

| 회기 | 주제 | 고객 중심 질문 | 주요 산출물 |
|---|---|---|---|
| 1회기 | 경험 자산과 현재 위치 | “나는 어떤 경험을 통해 무엇을 배워왔는가?” | 경험 자산 목록 |
| 2회기 | 가치·강점·환경 조건 | “나는 어떤 일·환경에서 나다워지는가?” | 커리어 방향성 문장 |
| 3회기 | 미래 방향과 가설 | “앞으로 더 많이 경험하고 싶은 일은 무엇인가?” | 커리어 가설·이정표 |
| 4회기 | 선택지·장애·실험 | “무엇이 나를 막고 무엇을 검증할 수 있는가?” | 탐색 행동·선택지 지도 |
| 5회기 | 자기주도 경력관리 | “앞으로 나는 어떻게 탐색하고 조정할 것인가?” | 경력 자기관리 계획 |

## 18.4 커리어 가설 문장

> “나는 **[다루고 싶은 문제·대상]**과 관련된 일을 할 때,  
> **[활용하고 싶은 강점]**을 사용하며,  
> **[선호 환경·가치]**가 있는 조건에서  
> 의미와 성장 가능성을 느낄 수 있을 것 같다.”

**예시**

> “나는 복잡한 정보 때문에 어려움을 겪는 사람과 관련된 일을 할 때, 정보를 구조화하고 쉽게 설명하는 강점을 사용하며, 함께 배우고 피드백하는 환경에서 의미와 성장 가능성을 느낄 수 있을 것 같다.”

## 18.5 커리어 코칭 질문

- “어떤 활동에서 시간 가는 줄 모르고 몰입했나요?”
- “어떤 문제를 다룰 때 의미를 느끼나요?”
- “이미 해온 경험 중 앞으로도 활용하고 싶은 것은 무엇인가요?”
- “진로를 선택할 때 남의 기준과 내 기준은 어떻게 다른가요?”
- “관심 분야를 작게 경험해 본다면 무엇을 해볼 수 있나요?”
- “그 경험이 나에게 맞는 방향인지 판단하려면 무엇을 관찰할까요?”
- “어떤 환경에서 고객님의 강점이 가장 잘 살아날까요?”

## 18.6 커리어 코칭 Between Session 예시

| 의제 | 행동 실험 | 관찰 기준 |
|---|---|---|
| 직무 관심 탐색 | 관심 직무의 실제 과업 하나 조사·요약 | 흥미, 이해도, 더 알고 싶은 질문 |
| 강점 발견 | 과거 프로젝트 하나를 STAR™ 방식으로 정리 | 반복 강점, 문제 해결 방식 |
| 환경 적합성 | 관심 조직·직무의 업무 환경 조건 정리 | 내 가치와의 적합성 |
| 자기효능감 | 하루 15분 관심 분야 학습 | 시작 장벽, 몰입, 피로도 |
| 비교 불안 | 비교가 발생한 순간 기록 | 비교 기준, 내 기준, 감정 변화 |
| 진로 가설 | 관심 분야에서 짧은 결과물 만들기 | 에너지, 강점 사용감, 지속 의향 |

# 19. 멘토링 코칭 적용 가이드

## 19.1 멘토링 코칭의 정의

멘토링 코칭은 멘토의 경험과 전문성을 활용하되, 멘토가 답을 정하거나 멘티의 삶을 대신 설계하지 않고, 멘티가 자신의 가치·목표·상황을 바탕으로 선택하고 성장하도록 돕는 관계 기반 코칭 방식입니다.

> **멘토링 코칭은 경험과 전문성을 가진 멘토가 멘티와 신뢰 기반 관계를 형성하고, 멘티의 목표·가치·강점·상황을 존중하면서 질문, 경청, 선택적 경험 공유, 성찰, 행동 지원을 통해 멘티의 자기주도적 성장을 돕는 과정이다.**

청소년 멘토링 관련 자료는 프로그램 효과를 위해 명확한 목표, 적절한 매칭, 사전교육, 관계 형성, 일관된 만남, 지속적 지원과 감독, 정기적 평가가 중요하다고 제시합니다. [youth](https://youth.gov/youth-topics/mentoring/best-practices-mentoring-relationships-and-programs)

## 19.2 일반 코칭과 멘토링 코칭 비교

| 구분 | 일반 코칭 | 멘토링 코칭 |
|---|---|---|
| 중심 | 고객의 자각·선택·행동 | 멘티의 자각·선택 + 멘토 경험의 선택적 활용 |
| 역할 | 질문·경청·반영 중심 | 질문·경청 중심 + 동의 후 경험 공유 가능 |
| 지식 활용 | 고객의 경험·자원 중심 | 멘토 경험은 참고자료 |
| 의제 | 고객이 결정 | 멘티가 결정하되 멘토와 공동 조율 |
| 행동 | 고객이 결정 | 멘티가 결정하고 멘토는 성찰 지원 |
| 핵심 위험 | 코치가 조언자로 변질 | 멘토 경험이 정답·지시로 변질 |
| 종료 목표 | 자기성찰·자기조절 | 멘티 자립·자원 확장·지속 성장 |

## 19.3 멘토링 코칭 핵심 원칙

### 멘티의 목표가 우선이다

> “멘티님이 이 관계에서 가장 얻고 싶은 것은 무엇인가요?”  
> “이번 만남에서 가장 먼저 정리하고 싶은 것은 무엇인가요?”

### 경험 공유는 허락 후 한다

> “비슷한 상황에서 제가 경험한 사례가 하나 있는데, 잠시 들어보는 것이 도움이 될까요?”

### 경험 공유 후 선택권을 돌려준다

> “이 경험 중 멘티님에게 맞는 부분은 무엇인가요?”  
> “맞지 않거나 다른 부분은 무엇인가요?”  
> “이 이야기를 들은 뒤 무엇을 참고하고 싶나요?”

### 멘토는 유일한 자원이 되지 않는다

> “이 목표를 위해 멘토인 저 외에 어떤 도움이 필요할까요?”  
> “이미 연결되어 있거나 새롭게 알아볼 수 있는 자원은 무엇인가요?”

### 관계의 일관성과 경계를 지킨다

- 약속한 시간과 방식을 가능한 한 지킨다.
- 변경이 필요하면 사전에 알리고 대안을 제시한다.
- 멘티의 사생활과 선택을 통제하지 않는다.
- 멘티가 불편함이나 관계 조정 요구를 말할 수 있게 한다.
- 금전, 선물, 개인 연락, SNS, 사적 만남의 기준을 사전에 합의한다.

## 19.4 멘토링 코칭 5회기 설계

| 회기 | 주제 | 멘티 중심 질문 | 멘토링 코칭 행동 | 주요 산출물 |
|---|---|---|---|---|
| 시작 세션 | 관계·기대·경계·목표 | “이 관계에서 무엇을 얻고 싶은가?” | 역할·경계·소통·기대 합의 | 멘토링 코칭 합의서 |
| 1회기 | 나의 이야기와 현재 위치 | “나는 어떤 경험을 지나왔는가?” | 경청·반영·강점 발견 | 멘티 자기이야기 |
| 2회기 | 가치·강점·성장 기준 | “나는 무엇을 중요하게 여기고 어떤 힘이 있는가?” | 가치·강점·환경 조건 탐색 | 방향성 문장 |
| 3회기 | 미래 방향과 자원 | “어떤 미래를 경험하고 싶고 무엇이 필요한가?” | 미래상·자원·지원망 탐색 | 미래 방향·자원 지도 |
| 4회기 | 선택지·행동·도움 요청 | “무엇을 시도하고 누구의 도움을 구할 것인가?” | 선택지 확장·작은 행동·지원 요청 설계 | 행동·지원 계획 |
| 5회기 | 성장 통합·자립·종료 | “앞으로 어떻게 성장과 선택을 이어갈 것인가?” | 배움 통합·자기질문·자원 지도 정리 | 지속 계획·관계 회고 |

## 19.5 멘토 경험 공유 프로토콜: SHARE

| 단계 | 의미 | 멘토 발화 예시 |
|---|---|---|
| S — Seek Permission | 경험 공유 허락 구하기 | “제 경험을 잠시 나누는 것이 도움이 될까요?” |
| H — Highlight Context | 경험의 배경·조건·한계 밝히기 | “제 경우에는 당시 이런 환경과 조건이 있었습니다.” |
| A — Add One Insight | 핵심 통찰 하나만 짧게 공유 | “제가 배운 점은 처음부터 완벽히 정할 필요는 없다는 것이었습니다.” |
| R — Return Choice | 멘티에게 해석·선택권 돌려주기 | “이 경험 중 멘티님에게 맞는 부분은 무엇인가요?” |
| E — Explore Action | 멘티 행동과 학습으로 연결 | “그렇다면 무엇을 작게 시도해볼 수 있을까요?” |

## 19.6 멘토링 코칭 피드백 가이드

| 피드백 원칙 | 권장 표현 | 피해야 할 표현 |
|---|---|---|
| 사실 중심 | “이번 주 계획 세 번 중 두 번을 시도하셨네요.” | “노력을 많이 하셨네요.” |

# 25. 별첨 A: GROW 코칭 모델

## 25.1 정의

GROW 코칭 모델은 코치가 직접 정답을 주기보다 질문을 통해 상대방이 스스로 해결책을 찾고 행동하도록 돕는 대표적인 문제해결 및 코칭 프레임워크입니다.

GROW는 목표 설정과 문제 해결을 위한 간단한 구조로 널리 활용되며 Goal, Reality, Options, Will의 네 단계로 구성됩니다. [cdn.southampton.ac](https://cdn.southampton.ac.uk/assets/imported/transforms/content-block/UsefulDownloads_Download/59CB199C2A5841109BF2EA4EA98017B6/GROW-Model.pdf)

> GROW는 질문을 구조화하는 프레임이지, 고객의 이야기를 네 단계에 억지로 끼워 맞추는 규칙이 아닙니다.

## 25.2 핵심 특징

| 특징 | 설명 |
|---|---|
| 자기주도성 | 코치가 정답을 주지 않고 고객이 스스로 생각·선택 |
| 목표지향성 | 원하는 결과를 명확히 하여 대화 초점 형성 |
| 현실기반성 | 현재 상황·자원·장애를 객관적으로 확인 |
| 선택지 확장 | 다양한 대안과 해결책 탐색 |
| 실행 연결 | 행동·시점·지원·실행 의지 확인 |
| 범용성 | 리더십, 피드백, 개인 목표, 학습, 스포츠 등 적용 가능 |

## 25.3 GROW 4단계

| 단계 | 의미 | 핵심 목적 | 산출물 |
|---|---|---|---|
| G — Goal | 목표 설정 | 원하는 최종 결과 또는 이번 대화의 목표 명료화 | 목표·성공 기준 |
| R — Reality | 현실 파악 | 현재 상황, 자원, 장애물 객관적 점검 | 현실 인식 |

# 26. 별첨 B: CiT STAR™ 코칭대화모델

## 26.1 정의와 정정

본 가이드북에서 사용하는 STAR™는 일반적인 업무 피드백 모델인 `Situation–Task–Action–Result`가 아닙니다.

여기서 STAR™는 **CiT코칭연구소의 코칭대화 프로세스 모델**이며 다음 네 단계로 구성됩니다.

\[
\textbf{S}tory \rightarrow \textbf{T}arget \rightarrow \textbf{A}ction\ Plan \rightarrow \textbf{R}ecap
\]

CiT는 STAR™를 고객의 고유한 이야기를 중심에 두고 주도성, 명료성, 의미 있는 성장을 지원하는 4단계 대화 모델로 제시합니다. [citkorea.co](https://www.citkorea.co.kr/05/01.php)

## 26.2 STAR™ 4단계

| 단계 | 의미 | 핵심 목적 | 산출물 |
|---|---|---|---|
| S — Story | 스토리 말하기 | 고객이 생각·상황·고민·감정·맥락을 자유롭게 풀어냄 | 핵심 맥락 |
| T — Target | 목표 수립하기 | 고객이 진정으로 원하는 목표와 방향 발견·합의 | 소목표·대목표 |
| A — Action Plan | 실행계획 세우기 | 행동·자원·장애 대응 설계 | 행동계획 |
| R — Recap | 마무리하기 | 깨달음·배움·실행 의지 정리 | 통찰·다음 행동 |

## 27.3 도구 1: 자기 이야기와 문제 외재화

### 목적
